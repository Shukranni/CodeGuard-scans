# Requirements for the FREE hosting tier (Render free plan, 512 MB RAM).
#
# It is identical to `requirements.txt` except that **semgrep is omitted from
# this file on purpose**: it adds hundreds of MB of binaries, and a pip
# failure here would fail the entire build.  `render.yaml` installs it as a
# separate best-effort step right after this file:
#
#     pip install --no-cache-dir semgrep || echo "…continuing without it"
#
# so a host that runs out of disk or network simply skips the scanner instead
# of failing to deploy.  At scan time the worker runs it with small-host
# guardrails (CODEGUARD_SEMGREP_JOBS=1, CODEGUARD_SEMGREP_MAX_MEMORY=192 in
# render.yaml); if it still cannot run, the scan reports semgrep as *skipped*
# while gitleaks and npm audit complete normally.
